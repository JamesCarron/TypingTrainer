The reading surface — three ways to make a typing line look like a book

Both requested changes are in all three: the measure runs right out to the collapsed rails, and an expanding wing simply overlaps the text. What differs is how each one solves the problem underneath the Reader look — a book page wants proportional type, and proportional type reflows when characters are substituted. A line that shifts under your eye mid-word is worse than any amount of ugliness, so each variant buys stability a different way.

Live. Click the text and type the highlighted line — Enter finishes, Esc resets. Click either rail to open its drawer and watch it overlap the text. The width slider under each frame runs from 50 characters to full, which is flush with the rails.

AFacsimile — the book's own type, target always shown

The page is set in a serif at book leading, and the live line is set in the same serif, inline, so there is no visible seam between the text you are reading and the text you are typing. Stability comes from never substituting a glyph: the line always shows the book's characters, and typing only changes how they are treated — struck through in red where you went wrong, full ink where you were right, grey ahead of the caret. Nothing can reflow because nothing is replaced. What you actually typed appears in small monospace below, so a wrong character is still legible.

Why it might winIt is the only one that genuinely looks like a book while you type: one typeface, one leading, the live line indistinguishable from the prose around it until you touch it. Proportional serif at this size is also simply easier to read for long stretches than monospace.
What it costsYou never see your own wrong character in place — the book's letter stays and turns red, and what you typed is relegated to a small line beneath. For a trainer that is a real loss: seeing what you hit instead is half the feedback.

BLifted line — a monospace band set into the page

The page around you is a book: serif, book leading, real context above and below. The line you are typing is lifted out of that flow into a monospace band with an accent edge — visibly a different kind of object, because it is one. Monospace means characters can be substituted freely with no reflow at all, so you see exactly what you typed, wrong letters and all. This is the original Reader mockup, tightened.

CTypewriter — one continuous text that scrolls under a fixed cursor

No lines at all, visually. The book runs as continuous prose and you type through it; text behind the cursor is in full ink, text ahead is grey, and the page scrolls so the cursor stays at the same height on screen — the typewriter scroll that writing apps use. The line boundaries still exist underneath, because the criteria are per line, but you never see one. Stability comes the same way as A: the book's glyphs are never replaced.
